## Findings that drive development

- Start with a five-minute listening lesson and a small contrast, then offer the whole English sound chart as a reference.
- Combine symbol, reviewed speech, plain Chinese articulation guidance, and a familiar word. Add short retrieval exercises and later review.
- Keep a consistent British dictionary notation while labelling legitimate pronunciation variants. The traditional 44-entry chart is a teaching model.
- Credible listening references and permission to redistribute recordings are separate questions. Four file-specific audio candidates are documented; none has been downloaded or auditioned for this project.
- Build a local static application first. A reviewed audio supply, rather than application complexity, is the main content dependency.

The design is a recommendation based on source research, not a validated claim about this specific learner population. No learner study, full accessibility audit, live browser interaction test, or acoustic/audio quality review has been performed. Some Cambridge and dynamic pages were readable only through indexed excerpts; these limits are recorded. Research dates are access dates, not claims that older teaching material was newly published in 2026.
